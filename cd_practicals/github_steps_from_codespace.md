# Commands For normal use:
```
1. cd /workspaces/TOC-and-CD-Practicals
2. git pull --rebase origin main
3. git add .
4. git commit -m "Add practical files"
5. git push origin main
```

# Remember
1. pull   → Get changes from GitHub
2. add    → Select your files
3. commit → Save changes locally
4. push   → Upload changes to GitHub
